## Core Directives for the Agent
1. **Never use emojis as icons**: Always use vector SVG icons (`lucide-react`, `@heroicons/react`, `@expo/vector-icons`).
2. **Distinctive Aesthetic**: Make bold, intentional visual choices tailored specifically to the project topic (Recruitment & Job Matching).
3. **Fluid Motion**: Add subtle micro-interactions, spring press states (`active:scale-95`), and smooth scroll transitions.
4. **Zero Layout Shifts & Zero Horizontal Scroll**: Ensure layout stability with aspect ratios and tested responsive breakpoints (375px to 1440px).
