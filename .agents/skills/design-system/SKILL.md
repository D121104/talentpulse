# Design System & UI/UX Standards

This skill provides design tokens, visual guidelines, and UI/UX aesthetic rules to ensure premium and polished user experiences.

## 1. Visual Excellence & Aesthetics
- **Color Harmony**: Use tailored color palettes with clear semantic roles (primary, secondary, accent, surface, neutral, error, success). Avoid default raw RGB colors.
- **Dark Mode Support**: Ensure dark mode has adequate contrast ratios (WCAG AA compliant) with deep grays/slates instead of pure #000000.
- **Typography**: Use modern typography scales with clear visual hierarchy (Display, H1-H6, Subtitle, Body, Caption).
- **Glassmorphism & Gradients**: Use subtle backdrop filters, soft gradients, and modern borders with low opacity for a sleek, premium feel.

## 2. Layout & Spacing
- **8-point Grid System**: All margins, paddings, and heights should adhere to multiples of 4px / 8px (e.g. 4, 8, 12, 16, 24, 32, 48, 64px).
- **Border Radius**: Consistent rounding across elements (e.g., small: 6px, medium: 12px, large: 20px, pill: 9999px).
- **Shadows & Elevation**: Layered, soft shadows to create depth hierarchy.

## 3. Micro-Interactions & Animation
- Subtle hover, focus, active, and pressed feedback.
- Smooth transitions (`cubic-bezier` or spring animations, 150ms-300ms duration).
- Skeleton loaders instead of disruptive layout shifts.
